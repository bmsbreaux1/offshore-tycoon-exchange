# offshore-tycoon-exchange

Two browser apps for the Gulf of America offshore market, built as Claude artifacts.

## Offshore Tycoon

A boat-operator game. Build a fleet, take charters, run the Gulf.

- Play: https://claude.ai/artifact/FVNwXsfhkJ8ubuNjeSFVhw
- Real vessel classes, including an autonomous vessel you can drive in the Gulf
- Historical Vessels mode: classic Lafourche OSV fleets and liveries
- Synthesised theme music; no audio files

## Offshore Exchange

A market-intel desk for the Gulf: the 2014 Offshore Exchange (OSX) concept, rebuilt.

- Open: https://claude.ai/artifact/JHrXGFtKDqAA5NhUUjZLNk
- BSEE / BOEM block lookup by block, lease, field or API number
- Vessel search across a working vessel database
- No pricing or day rates, by design

## Background

I founded The Offshore Exchange in 2015: a B2B marketplace and logistics platform for offshore energy. These two apps are that idea, rebuilt ten years later by one person with an AI coding agent.

## Built with

Claude Code, single-file HTML / JavaScript, public BSEE and BOEM data.
